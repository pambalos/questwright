## Voice and narration (ElevenLabs)

ElevenLabs' strength is audio, through a proper developer API; their image tools only resell other companies' models, so illustrations go straight to the image providers instead.

- **Codex narration:** a "Read aloud" button on codex entries, in a narrator voice.
- **Character voices:** design a voice for each main character from the traits in the memory graph, and play their collected "said" quotes in it.
- **System messages:** a short chime and a narrated reading of system boxes.
- **Setup:** an ElevenLabs API key in Settings, stored like the other provider keys (encrypted, desktop main process only). Cache generated audio per entry and version it the same way illustrations are, so a quote is only voiced once.
